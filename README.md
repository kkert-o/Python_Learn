# Python 学习 App

这是根据产品提示词搭建的 Android 原生工程，使用 Kotlin、Jetpack Compose 和 Material 3。

## 当前已实现

- App 外壳：首页 / 课程 / 练习 / 项目 / 我的 五个入口
- 首页：等级与经验、继续学习、每日任务、连续学习天数
- 课程：五个学习阶段、知识点状态，新用户从 Python 是什么 开始
- 知识点详情：统一 10 段模板，含知识讲解、示例、小练习、常见错误、法律与合规
- Python 运行台：手机端内置真实 Python 3.11，包含 requests 与 BeautifulSoup，可编辑代码、为 input 提供输入内容、运行并查看通俗化报错说明
- 编程能力训练：看代码、预测输出、代码补全、Debug Lab 四类专项训练，带分级提示、运行验证、参考实现和训练进度
- 练习：4 道即时判题，答完会显示本次成绩
- 项目：计算器、猜数字、BMI 计算器、通讯录的需求、分步提示与起始代码
- AI Python 老师：老师模式/只给思路等学习模式；默认 DeepSeek 接口，填写 API Key 后使用真实大模型，未配置时使用本地引导模式
- 外观：浅色 / 深色 / 跟随系统、主色切换
- 壁纸：内置 5 套配色壁纸
- 自定义壁纸：从系统相册选图作为背景，并带毛玻璃效果
- 进度闭环：完成课程后自动解锁下一课，进度会保存在本地
- 项目完成状态：4 个项目均可分别完成并持久保存
- 错题本：练习、课程小练习和专项训练未通过都会进入待复习清单，复习答对自动移出
- 自动复习：错题本支持逐个复习与一键复习全部错题
- 学习数据底座：课程、项目、训练和错题进度使用 Room 持久化，并自动迁移旧版本地数据
- 知识状态引擎：根据课程、训练和答题记录计算掌握度，生成复习队列与下一步推荐，并按 1 / 3 / 7 / 14 / 30 天安排复习
- 内容与程序分离：课程和项目正文存放在可独立更新的 JSON 资源中，加载失败时自动使用内置兜底内容
- 内容更新接口：支持远端版本清单、最低 App 版本检查、SHA-256 校验、原子替换和损坏内容回退；配置地址后由 WorkManager 每 24 小时自动检查，接口说明见 `docs/content-update.md`
- 法律地区：中国大陆 / 日本 / 美国 / 欧盟 / 其他 可切换并持久保存
- 设置持久化：主题、主色、壁纸、课程进度、项目进度、错题、法律地区都会保存在本地
- 课程内容：10 个学习阶段共 42 个知识点全部可学，覆盖 Python 基础、控制流程、数据结构、函数与文件、网络爬虫、数据分析、数据库、Web API、AI 应用与工程化
- 学习中心：知识树、掌握度、知识点状态、到期复习和下一步推荐可视化
- 高级代码编辑器：行号、语法高亮、括号匹配、自动缩进、复制、清空、格式化、停止运行、字号与行高、自动换行、缩进线、7 套预设主题和自定义颜色
- 错误博物馆：8 类高频错误，提供表现、原因、错误代码、修复代码和预防清单
- Debug 训练：覆盖 NameError、SyntaxError、TypeError、ValueError、IndexError、KeyError、AttributeError 和文件路径问题
- 全局搜索与收藏：统一搜索课程、项目、训练、第三方库、错误和工程实践，并支持本地收藏
- 第三方库生态：内置网络、数据、数据库、Web、测试、AI 和工程工具目录
- 工程实践：Git 工作流、代码质量与最小自动化测试闭环
- 项目内容：13 个项目覆盖 Lv.1 到 Lv.5，包含最终毕业项目验收要求
- AI 独立能力：AI 等级、AI 依赖指数和 6 项 AI-Free Challenge
- 发布检查：把应用版本、设备信息、Python 运行时 smoke test、功能完成情况和 Release 签名配置集中在“我的 > 发布与设备检查”
- Release 签名：支持通过未提交到 Git 的 `keystore.properties` 注入正式签名，说明见 `docs/release-signing.md`
- 学习数据：我的页面按课程和项目进度实时计算等级、阶段完成度和能力数据

## 打开方式

用 Android Studio 打开 `PythonApp` 目录，等待 Gradle Sync 完成后直接运行到模拟器或手机。

环境要求：

- Android SDK 36
- Python 3.11（用于打包第三方 Python 库，工程已配置本机路径）
- JDK 17 或更高版本（Android Studio 自带 JDK 也可以）
- Gradle 9.7.1（工程已带 Wrapper，Android Studio 会自动下载）
